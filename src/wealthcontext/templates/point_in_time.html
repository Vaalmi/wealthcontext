How to read the two lists

  • A receipt is a feed run that first delivered records the snapshot cites at that cutoff. Each list is its own governed result.
  • A record that a later identical delivery repeats keeps its first run, so earlier receipts stay listed beside later ones.
  • A run whose records were all replaced is listed at the earlier cutoff and not at the later one.
  • {{ badge('info', 'Only in this list') }} marks a run ID the other list does not hold. It is shown only when neither list is capped, since a capped list cannot show what it left out.
